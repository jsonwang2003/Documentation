## Group Theory
### Stages of Group Development
1. Forming → Set up the team
2. Storming → Get to know each other
3. Norming → Set up some shared standard
4. Performing → Do what the team is tasked to do
5. Adjourning → share the result (party)

> 1 person is all it takes to ruin a team

### Team Size
- Cannot be too big ($< 200$)
- As the size increases, the clarity of communication decreases
	- Use **hierarchy** to try organizing the huge team
	- Might need to skip out the hierarchy
	- Need to communicate between the same layer

### Composition
- Needs diversity of members
	- Specialists / Generalists

### Organization Cultures
- Pathological - Power oriented
- Bureaucratic - Rules oriented
- Generative

#### Conway's Law
Structure of Software will **mirror** the structure of the organization that built it
- Small distributed teams → modular, service architecture
- Large colocated teams → monolithic architecture

#### Culture is...
- Mostly Emerged
- Trust is built on **first impression**
