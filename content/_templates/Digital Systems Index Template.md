# Foundational Concepts

## Binary Representation

Every value in a digital system is ultimately represented in base 2 — see [[Number Systems, Logic Gates & Boolean Algebra#Number Encoding|Number Encoding]] for how binary, octal, and hexadecimal relate to each other.

## The Boolean Domain

$B = {0, 1}$ — every variable and every gate's output in this section is restricted to exactly these two values; see [[Number Systems, Logic Gates & Boolean Algebra#Common Logic Gates|Common Logic Gates]].
