> [!abstract] Abstract
> In a graph, there consists of many types of edges that connects from node to node.

---
## Concepts

### **Tree Edge (Forward Edge)**
A solid edge included in the DFS Output Tree, in other words, edges that have been visited by [[3. Depth First Search (DFS)|Depth First Search]] or [[1. Explore|Explore]]. This edge leads to a descendent.
$(u,v)$ is a tree/forward edge when:
$$
pre(u) < pre(v) < \underbrace{ post(v) < post(u) }_{ \text{determine here} } 
$$

### **Back Edge**
An edge that is not included in the DFS Output Tree that leads to an ancestor. Back edges in an undirected graph $G$ that has been explored are edges in $G$ that are not in the DFS tree of $G$ but connects vertices in the DFS output tree.
$(u,v)$ is a back edge when:
$$
pre(v) < pre(u) < \underbrace{ post(u) < post(v) }_{ \text{determine here} } 
$$

> [!info] Graph Cycles Theorem
> An undirected connected graph $G$ has a cycle if and only if it's DFS output tree has a back edge. Removing an edge that is in a cycle will not disconnect an undirected graph and removing an edge that is not in a cycle will disconnect an undirected graph.

### **Cross Edge**
An edge that is not included in the DFS Output Tree that leads to neither an ancestor nor descendent.
$(u,v)$ is a cross edge when:
$$
pre(v) < \underbrace{ post(v) }_{ \text{determine here} } < pre(u) < \underbrace{ post(u) }_{ \text{determine here} } 
$$
