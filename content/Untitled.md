DEFINITION & THREAT MODEL ---------------------------------------------------------------------------------------------------- • Definition: Exploits physical/implementation artifacts (timing, power, sound, cache) rather than software bugs to leak secrets across trust boundaries[cite: 28, 34]. • Principle: Implementation details leak secret state even if high-level abstraction is secure[cite: 28, 34]. • Attacker Model: Co-located execution (process, VM, user/kernel) sharing physical hardware[cite: 34]. 2. TAXONOMY & EXAMPLES ---------------------------------------------------------------------------------------------------- • Consumption Channels: Measures resource usage (time, power, memory, network size)[cite: 34]. - Timing: Early-exit string checks (strcmp)[cite: 34]; Tenex VM page-fault leak (linear time PWD recovery)[cite: 34]. - Network: HTTPS response packet sizes leak search box autocomplete inputs[cite: 34]. • Emission Channels: Out-of-band signals (RF, EM, heat, sound, light)[cite: 34]. - Power: SPA (visual trace inspection)[cite: 34], DPA (statistical signal processing across traces)[cite: 34]. - Physical: Acoustic keyboard emanations[cite: 34]; CRT/LCD display reconstruction via RF/diffuse light[cite: 34]; Thermal imaging of keypad PIN entry[cite: 34]. • Active Fault Injection: Inducing environmental glitches (voltage, clock, temperature, EM) to cause bit flips during secret operations to recover internal keys[cite: 5, 34]. • Covert Channel: Intentionally constructed side-channel link between two cooperating parties to exfiltrate data across enforced isolation boundaries (e.g., >45 KBps SSH over EC2 cache channel)[cite: 34]. 3. SPECULATIVE EXECUTION & HARDWARE FLAWS ---------------------------------------------------------------------------------------------------- • Meltdown: CPU speculatively executes instructions using target data before evaluating page table Ring 0 privilege checks[cite: 32, 34]. Leaves secret state in L1 cache[cite: 32, 34]. Recovered via Flush & Reload[cite: 31, 34]. - Mitigation: KPTI (Kernel Page Table Isolation - unmaps kernel memory from user page tables)[cite: 34]. • Spectre: Trains CPU branch predictor to speculatively execute out-of-bounds reads `if (x < size)`, leaving microarchitectural cache traces of out-of-bounds data[cite: 32, 34]. - Mitigation: Speculation fences (lfence), retpolines[cite: 34]. • Rowhammer: Repeatedly accessing ("hammering") adjacent DRAM rows induces electrical bit flips in target rows via capacitive coupling[cite: 34]. Mitigated via ECC memory & Target Row Refresh (TRR)[cite: 34]. 5. GENERAL DEFENSES ---------------------------------------------------------------------------------------------------- • Constant-Time Code: Eliminate secret-dependent branches and secret-dependent memory indexing[cite: 5, 34]. • Hardware Isolation: Flush caches across context switches; isolate cache ways per process[cite: 34].
