> [!abstract] Overview
> **Logic Design** focuses on translating functional behavioral requirements into optimized physical gate-level combinational circuits. This submodule covers logic function specification via truth tables and schematics, standardized **Canonical Representations** (Sum-of-Products and Product-of-Sums), fundamental arithmetic circuits (Half and Full Adders), and systematic **Two-Level Logic Simplification** using the Uniting Theorem, Boolean hypercubes, and Karnaugh Maps (K-maps) with Don't Care condition exploitation.

---

## Submodule Notes

- [[Computer Systems/Digital Systems/Logic Design/Logic Functions|Logic Functions]]  
  Converting Boolean equations to logic gate circuits, specifying combinational logic via truth tables, designing Half Adders and Full Adders, and foundational definitions (literals, implicants, implicates, minterms, and maxterms).

- [[Computer Systems/Digital Systems/Logic Design/Canonical Representation|Canonical Representation]]  
  Standardized Sum of Products (SOP / Disjunctive Normal Form) using minterms ($\Sigma m$), Product of Sums (POS / Conjunctive Normal Form) using maxterms ($\Pi M$), index shorthand conversions, algebraic reduction, and SOP vs. POS selection strategies.

- [[Computer Systems/Digital Systems/Logic Design/Logic Simplification with K-maps|Logic Simplification with K-maps]]  
  Two-level logic minimization mechanics driven by the Uniting Theorem ($AB' + AB = A$), geometric Boolean hypercubes, 3 and 4-variable K-maps with Gray code ordering, Don't Care ($X$) outputs, Prime Implicants (PIs), Essential Prime Implicants (EPIs), and the systematic covering algorithm.
