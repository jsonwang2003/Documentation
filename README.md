# My Digital Garden

Welcome to my personal digital garden! This is a public, evolving repository of my academic journey, technical knowledge, self-directed research, and intellectual exploration. 

Unlike a traditional static blog, this space acts as a networked knowledge base—a collection of interconnected notes, ideas, and concepts that grow and change over time.

---

## Purpose & Philosophy

The primary objective of this garden is to document and synthesize my entire educational journey. It serves several core functions:
* **Knowledge Retention:** Translating complex academic topics, lectures, and technical documentation into my own words to build deep, intuitive understanding.
* **Networked Thinking:** Connecting overlapping concepts across different domains (e.g., how theoretical computer science influences practical systems engineering or robotics).
* **Progress Tracking:** Preserving a living archive of my growth, projects, milestones, and problem-solving methodologies throughout my studies.
* **Open Source Learning:** Sharing my notes transparently with peers, collaborators, and anyone interested in the same fields of study.

---

## How to Navigate the Garden

The notes here are highly interconnected using bi-directional links. Because the garden is currently centered on my core computer science foundations, you can start exploring from these active technical hubs:

* **Theory & Foundations:** Notes covering computational complexity, theoretical foundations, discrete mathematics, and academic coursework.
* **Systems & Low-Level Architecture:** Deep-dives into operating systems, kernel mechanics, process management, and systems-level programming.
* **Applied Engineering & Projects:** Lab work, architectural breakdowns, core development frameworks, and post-mortems of software I am actively building.
* **Permanent Notes:** Highly atomic, polished ideas that summarize standalone concepts, algorithmic patterns, or technical mental models.

*Note: As my educational journey progresses, other dimensions of my academic and research interests will be integrated into the graph.*

## 🛠️ Built With

This digital garden is built using **[Quartz](https://quartz.jzhao.xyz/)**, a powerful, fast, and highly customizable framework created by [Jack Zhao](https://github.com/jackyzha0) for publishing Markdown notes. 

I am incredibly grateful to the Quartz community for providing a robust template that handles graph visualization, bi-directional linking, fast full-text search, and seamless generation of web-ready static pages straight out of the box.

### Local Development

If you have cloned this repository and want to run it locally:

1.  **Install Dependencies:**
    ```bash
    npm install
    ```
2.  **Start the Local Server:**
    ```bash
    npx quartz build --serve
    ```
3.  **Preview:** Open `http://localhost:8080` in your browser.
